เชื่อมต่อ Google Sheets

กรอก Web App URL หลังจากติดตั้ง Code.gs และ Deploy แล้ว

URL ของคุณถูกฝังใน HTML แล้วและจะถูกใช้เป็นค่าเริ่มต้นเสมอ บัญชี Admin จดจำการเข้าสู่ระบบได้บนอุปกรณ์ส่วนตัว โดยไม่บันทึกรหัสผ่าน

ขั้นตอนการติดตั้ง

01
นำเข้าไฟล์ Excel เป็น Google Sheets

เปิดไฟล์ แล้วเลือก ส่วนขยาย → Apps Script

02
วางโค้ดจาก Code.gs

คัดลอกโค้ดทั้งหมด และรันฟังก์ชัน setupAdminRegistration เพื่อสร้างรหัสเปิดใช้งาน แล้วสมัครบัญชี Admin ครั้งแรก

03
Deploy เป็น Web App

เรียกใช้ในนามเจ้าของไฟล์ เลือกให้บุคคลทั่วไปเข้าถึงได้เฉพาะ API และเก็บ URL ที่ลงท้าย /exec

04
นำ URL มาใส่ในช่องด้านซ้าย

ทดลองส่งข้อมูลและเข้าสู่ระบบ Admin ก่อนเปิด Dashboard
